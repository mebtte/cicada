# PWA

## Requirement

- [Node.js](https://nodejs.org) environment

## Start DEV Server

```sh
npm install
npm run dev
```

And the `pwa` can be visited on `http://localhost:8001`.

## Components Docs

`cicada` has own components. Visit its docs on `http://localhost:6006` by running:

```sh
npm run storybook
```
